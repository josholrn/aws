# Exam Preparation

## Review approach
* Revisit the official AWS Certified Developer Associate exam guide and use practice questions to identify weak areas. The course recommends hands-on experience rather than relying on memorization alone.
* Practice deploying an application with different compute and delivery options, adding SQS/SNS decoupling, creating a CI/CD pipeline, and automating AWS tasks with the CLI or SDK.
* Exam questions are usually scenario-based. Eliminate clearly unsuitable choices, then select the simplest option that meets the stated requirements; avoid overcomplicating a workable scenario.
* For additional context, review AWS whitepapers such as the Well-Architected Framework, Security Best Practices, and guidance on serverless architectures and CI/CD.
