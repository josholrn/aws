# Exam Preparation

## Study and practice

### Review the objectives

Use the current AWS Certified Developer – Associate exam guide to check the tested domains and objectives; this course is a broad survey, not a substitute for the current guide. Revisit weak topics with hands-on practice and service FAQs, which often clarify behaviors and limits that appear in scenario questions.

The course recommends practical experience developing and maintaining AWS applications, rather than relying on memorized service names alone. Build or adapt an application and try more than one deployment path:

* Deploy it on EC2, then Elastic Beanstalk.
* Decouple components with SQS and SNS.
* Create a CI/CD pipeline.
* Where appropriate, run parts on Lambda.

Write CLI or SDK automation—for example, scheduled EC2 start/stop, EBS snapshots, or reports of under-utilized instances. This makes service trade-offs and integration behavior concrete.

### Use reference material and practice questions

Review relevant AWS whitepapers, especially:

* Well-Architected Framework.
* Security Best Practices.
* Cloud best practices.
* CI/CD and DevOps.
* Microservices.
* Serverless architectures.
* Containerized microservices.
* Blue/green deployments.

Use the service FAQs and practice questions to test understanding. When an answer is wrong, revisit the underlying behavior or requirement rather than memorizing only the selected option.

## Approach scenario questions

Questions are primarily scenario-based. Identify the actual requirement first—latency, durability, security, operational effort, scale, or cost—then eliminate options that cannot meet it.

Among the remaining choices, prefer the simplest AWS-native solution that satisfies the stated constraints. Avoid adding services or complexity the scenario does not require, and do not mistake a technically possible solution for the best fit.

## Confirm exam logistics

The slide deck describes a 65-question, 130-minute exam, a 720/1000 passing score, and a retake interval of 14 days after a failure. It also describes online registration, identity-document requirements, and the option to flag questions and return to them.

Exam logistics, fees, delivery rules, and scoring policies can change; confirm them on the official certification page before booking. Budget time for a final review of flagged items and follow the current exam-provider instructions.
